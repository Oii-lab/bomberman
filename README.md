# 💣 Bomberman Online

兩人即時連線炸彈超人對戰遊戲。

🎮 **線上遊玩：** https://bomberman-online-1yh4.onrender.com

---

## 玩法

把網址傳給朋友，兩人輸入相同的房間 ID 即可開始對戰。

| 玩家 | 移動 | 放炸彈 |
|------|------|--------|
| 🔴 P1 | `WASD` | `Space` |
| 🔵 P2 | `↑↓←→` | `Enter` |

- 💣 炸彈 3 秒後爆炸，射程 2 格
- 🧱 橘色磚塊可被炸毀
- 🔥 被火焰波及即淘汰
- 連鎖爆炸、每局隨機地圖
